# 🔊 Sticker WOW

Web para crear stickers con sonido para WhatsApp.

- Imagen: foto, video o emoji, con texto estilo meme, forma, borde y movimiento.
- Sonido: biblioteca de 18 sonidos de meme y canciones cortas (creados por código, sin derechos de autor), subir tu propio audio o video, grabar tu voz, o usar el sonido del video.
- Resultado:
  - **Sticker con sonido** → video cuadrado MP4 (WhatsApp no permite sonido dentro de un sticker, así que se envía como video corto).
  - **Sticker sin sonido** → imagen WebP 512×512, formato oficial de sticker de WhatsApp.

Todo funciona dentro del navegador: no hay servidor y nada se sube a internet.

## Publicarla gratis con GitHub Pages
1. En GitHub, abrí el repositorio → **Settings** → **Pages**.
2. En *Source* elegí **Deploy from a branch**, rama `main` (o la rama con estos archivos) y carpeta `/ (root)`. Guardá.
3. En 1–2 minutos aparece el enlace `https://<usuario>.github.io/STIKER_WOW/`.

## Navegadores recomendados
Chrome actualizado (Android / PC) o Safari (iPhone). Ambos generan MP4 compatible con WhatsApp.
