# 🔊 Sticker WOW

Web para preparar stickers con sonido para WhatsApp, paso a paso.

1. **Base:** foto, video o emoji.
2. **Recorte:** barra tipo editor de video con miniaturas para elegir hasta 5 s.
3. **Texto y estilo.**
4. **Sonido:** el original del video, un audio subido o tu voz grabada, con barra de recorte sobre la forma de onda.
5. **Listo:** crea un video de hasta 5 s con el sonido incluido. En WhatsApp: 😊 → Stickers → + Crear → elegir ese video.

Todo funciona dentro del navegador: nada se sube a internet.

## Publicarla gratis con GitHub Pages
Settings → Pages → Deploy from a branch → elegir la rama y la carpeta `/ (root)`.
